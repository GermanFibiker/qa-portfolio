# Ozon — Checklist (Поиск товара)

## Поиск

- [ ] Поле поиска открывается.
- [ ] Можно ввести текст.
- [ ] Поиск работает по одному слову.
- [ ] Поиск работает по нескольким словам.
- [ ] Поиск по цифрам.
- [ ] Пустой поиск обрабатывается корректно.
- [ ] Очистка поиска работает.

## Результаты

- [ ] Карточки товаров отображаются.
- [ ] Цена отображается.
- [ ] Изображения загружаются.
- [ ] Переход в карточку товара работает.

## Фильтры

- [ ] Фильтр по цене работает.
- [ ] Сортировка меняется.
- [ ] Фильтры сбрасываются.
