# BUG-002

## Название

Кнопка "Очистить поиск" не появляется после удаления текста.

## Тип

UI

## Приоритет

Low

## Шаги

1. Открыть поиск.
2. Ввести текст.
3. Удалить весь текст.

## Ожидаемый результат

Появляется кнопка очистки.

## Фактический результат

Кнопка отсутствует.

## Статус

Учебный баг-репорт.
