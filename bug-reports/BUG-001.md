# BUG-001

## Название

Поле поиска позволяет отправить пустой запрос.

## Тип

UI / Functional

## Приоритет

Low

## Окружение

- iPhone
- Safari
- Ozon

## Шаги

1. Открыть Ozon.
2. Нажать на поиск.
3. Не вводить текст.
4. Нажать кнопку поиска.

## Ожидаемый результат

Появляется сообщение «Введите запрос».

## Фактический результат

Открывается экран поиска без понятной подсказки пользователю.

## Статус

Учебный баг-репорт.
