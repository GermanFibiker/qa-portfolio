# Test Cases — Login

## TC-001 Успешная авторизация

Предусловие: Пользователь зарегистрирован.

Шаги:
1. Открыть страницу входа.
2. Ввести корректную почту.
3. Ввести корректный пароль.
4. Нажать «Войти».

Ожидаемый результат:
Пользователь попадает в личный кабинет.

---

## TC-002 Неверный пароль

Шаги:
1. Ввести правильную почту.
2. Ввести неправильный пароль.
3. Нажать «Войти».

Ожидаемый результат:
Появляется сообщение «Неверная почта или пароль».

---

## TC-003 Пустые поля

Шаги:
1. Не заполнять поля.
2. Нажать «Войти».

Ожидаемый результат:
Появляются сообщения о необходимости заполнить поля.
