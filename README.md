# QA Portfolio

Практическое портфолио начинающего QA Engineer.

## 🎯 О проекте

Учебный проект, созданный для практики ручного тестирования
и оформления тестовой документации.

## 📂 Содержание

### 🐛 Bug Reports

Примеры оформления найденных дефектов:

- BUG-001
- BUG-002

### 🧪 Test Cases

Тест-кейсы для основных пользовательских сценариев:

- Авторизация
- Работа с корзиной

### ✅ Checklists

Чек-листы для проверки функциональности интернет-магазина:

- Поиск товара
- Результаты поиска
- Фильтры

### 📊 Test Summary Report

Итоговый отчёт по проведённому тестированию.

## 🛠 Инструменты и технологии

- Manual Testing
- Test Cases
- Bug Reports
- Checklists
- Git
- GitHub
- Markdown

## 📌 Статус проекта

Учебный проект. Портфолио находится в процессе развития.
